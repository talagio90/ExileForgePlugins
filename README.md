# Exile Forge Plugin

An add-on app for **Path of Exile 2** from the Exile Forge team. It shows what a map holds (bosses, checkpoints, league content, shrines), counts kills, shows live prices and, if you switch them on, can help with routine tasks.

**It is included with Exile Forge Premium.** The app uses the Premium key you already activated in Exile Forge; without an active Premium key none of the plugins can be switched on.

## Download
Get `ExileForgePlugin-PoE2.zip` from the [latest release](../../releases/latest), extract it and run `ExileForgePlugin-PoE2.exe`. No installation. Needs Windows 10/11 x64. Path of Exile 2 only.

## Read this first
- Exile Forge Plugin **reads the memory of the game**, and some plugins (auto flasks, auto loot, auto stash, follow bot) **send clicks and key presses for you**.
- GGG's policy does not allow this and it can lead to **account bans**. Switch on only what you need, and use it at your own risk.
- The radar / kill tracker / price plugins only read the game; the automation plugins are off until you switch them on.

## Plugins
Radar, Expedition Planner, Kill Tracker, Ritual Prices, Runeshape Prices, Auto Flask, Auto Loot, Auto Stash, Follow.
